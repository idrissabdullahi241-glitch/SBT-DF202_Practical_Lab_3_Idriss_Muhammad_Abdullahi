- Name: Idriss Muhammad Abdullahi

## Overview

This repository contains evidence, screenshots, recovered files, hash values, and the final forensic report for Module 7 laboratory exercises.

The investigation covered:

- JPEG file signature analysis
- Hexadecimal examination using xxd
- Reverse-hexdump reconstruction
- Metadata and string analysis
- Binwalk embedded file discovery
- USB image preparation
- Scalpel file carving
- Hash verification using MD5 and SHA-256
